1. TABULADOR SSEPI (costos por empresa y módulo)
--------------------------------------------------------------------------------

Archivo principal:
  info\TABULADOR DE COTIZACIÓN actualizado.xlsx

Hojas:
  Hoja1          → Viaje / HR Dani (km, gasolina viaje, $ Dani). SOLO REFERENCIA.
  LABORATORIO    → Gasolina, ventas (reparación en visita), gastos generales,
                   utilidad 45%, CREDITO 3% (precio final al cliente).
  MOTORES        → Gasolina, BECERRA, GASTOS S/U, utilidad, CREDITO 3%.
  SUMINISTROS    → Gasolina, proveedor, GASTOS S/U, utilidad, CREDITO 3%.
  AUTOMATIZACIÓN → Servicios por columna (PLC, tablero, etc.) o TOTAL VENTA.

Generado por el comparador:
  info\datos_comparador.json      (JSON completo, ~MB)
  info\datos_embebidos.js         (mismo contenido para el HTML)
  info\rastro_capturas.json       (139 capturas, datos fiables por imagen)

Catálogo contactos Odoo (Excel export):
  info\contactos_odoo.xlsx

Capturas pantalla Odoo:
  info\SistemaContactos\CapturasOdoo\Screenshot*.png  (139 archivos)

2. ÓRDENES DE REPARACIÓN (editor)
--------------------------------------------------------------------------------

Salida del pipeline de reportes:

--------------------------------------------------------------------------------
3. JSON DEL COMPARADOR (estructura resumida)
--------------------------------------------------------------------------------

datos_comparador.json contiene:

  excel[]           — 50 empresas tabulador, cada una con:
                      name, rfc, modulos { laboratorio, motores, suministros,
                      automatizacion }, viajeDani { km, gasolina, ... }

  odoo[]            — 139 registros (una por captura) con:
                      nombreContacto, empresaAsociada, tipoFicha (empresa /
                      contacto_empresa / contacto_solo), excelMatch, matchScore

  tabuladorErp      — 50 empresas con gastos + contactos Odoo vinculados

  relacionErp[]     — Lista plana para exportar a calculadora:
                      empresaTabulador, modulos, contactosOdoo[]

  empresasOdoo[]    — Agrupación empresa → ficha + vendedores

  unmatched[]       — Capturas sin fila en tabulador
