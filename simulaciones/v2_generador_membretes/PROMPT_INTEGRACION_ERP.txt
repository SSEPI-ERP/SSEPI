ARCHIVOS CLAVE
--------------------------------------------------------------------------------
1. ssepi_servicios_enterprise_v11.html  -> HTML con generarPDF() y generarReportePDF()
2. membretes_base64.js                  -> Diccionario JPEG base64 (~1 MB)
3. convert_membretes.py                 -> Script para regenerar el diccionario

MOTOR PDF
--------------------------------------------------------------------------------
- jsPDF 2.5.1 + jspdf-autotable 3.5.28.
- Formato A4, unit:'mm'. PW=210, PH=297, ML=15, MR=15, TW=180.
- Membrete: JPEG base64 escalado a A4 completo: doc.addImage(b64, 'JPEG', 0, 0, PW, PH)
- Fuente única: 'times' (serif institucional) en TODO el documento. No usar 'helvetica'.
- jsPDF incluye fuentes built-in: helvetica, times, courier. Usar exclusivamente 'times'.
- Capa 0: membrete JPEG. Capa 1: textos dinámicos encima.

FLUJO DE PÁGINAS — COTIZACIÓN (generarPDF)
--------------------------------------------------------------------------------
Página 1: Membrete institucional completo (sin texto encima).
Página 2: drawHeader() + datos cliente + tabla productos + subtotal/iva/total.
           Tabla puede ocupar varias páginas si es larga (autoTable continuo).
Post-tabla: Tiempo de entrega + Notas + Términos de Pago (compactados, máx 1-2 páginas).
Footer drawFooter() en cada página.

ESTILO DE TABLA (ACTUALIZADO)
--------------------------------------------------------------------------------

- Filas alternadas: fondo verde claro [230,245,240] / blanco.

SEPARACIÓN NOTAS / TÉRMINOS DE PAGO
--------------------------------------------------------------------------------
Entre la última nota y la sección "Términos de Pago" se dibuja:
  1. ensureSpace(30) — verificar que quepa el espacio, sino salto de página.
  2. hl(ML, y, TW, GR_SEP, 0.4) — línea separadora horizontal.
  3. y += 10 — renglón en blanco de separación.

REGLAS DE ESTILO EN PÁGINA 1 (MEMBRETE)
--------------------------------------------------------------------------------
- NO dibujar rectángulos blancos ni fondos antes de addImage.
- Textos sobre membrete: ubicarse en sector central/blanco del diseño (aprox X=75–135 mm).

REGLA DE TIPOGRAFÍA
--------------------------------------------------------------------------------
- Todo el PDF usa 'times' exclusivamente. No usar 'helvetica' ni 'courier'.
- Tamaño mínimo de contenido: 12 pts.
- Footer puede quedar en 9 pts.

SI LOS MEMBRETES CAMBIAN EN EL FUTURO
--------------------------------------------------------------------------------
1. Reemplazar el PDF en la carpeta formatos/.
2. Ejecutar: python convert_membretes.py
3. Copiar el nuevo membretes_base64.js generado al proyecto destino.
4. Recargar la página (F5). No requiere recompilación.
