PRIORIDADES PARA LA CALCULADORA EN ODOO (siguiente fase)
--------------------------------------------------------------------------------

FASE A — Leer precios base (YA EXPORTABLE)
  - Importar relacion_erp_tabulador_odoo.json.
  - Por empresa: modulos.laboratorio.precioFinal, motores, suministros, automatizacion.
  - Mostrar desglose gasolina / gastos S/U / utilidad si se requiere transparencia.

FASE B — Nueva orden / cotización
  - Usuario elige: Empresa (lista 50 del tabulador + búsqueda alias).
  - Usuario elige: Módulo(s) LAB, MOT, SUM, AUTO.
  - Sistema carga precio base del módulo desde JSON o tabla sincronizada Excel.
  - Campos "costo extra" por tipo (ver VINCULACION_EMPRESAS_Y_COSTOS.txt).

FASE C — Unificar nombres orden ↔ tabulador
  - Tabla de alias (cliente en orden → empresaTabulador).
  - Sugerencia automática desde comparador (matchScore, sugerenciaExcel).

FASE D — Sincronización Excel
  - Cuando cambie TABULADOR DE COTIZACIÓN actualizado.xlsx:
    ejecutar build_comparador.py y republicar JSON en Odoo o carpeta compartida.

--------------------------------------------------------------------------------
REGLAS DE NEGOCIO A RESPETAR EN CÓDIGO
--------------------------------------------------------------------------------

  - Hoja1 del Excel NO es el precio del módulo; es viaje/HR Dani.
  - LAB: precio al cliente = CREDITO 3%; costo operativo ≈ GASTOS GENERALES.
  - MOT/SUM: incluir BECERRA o PROVEEDOR cuando aplique.
  - AUTO: puede ser solo gasolina + TOTAL VENTA si no hay servicios desglosados.
  - Algunos clientes tienen números solo en AUTO (ej. DI CENTRAL); no forzar LAB.

  - No sumar el mismo viaje dos veces (módulo gasolina + Hoja1 km).
