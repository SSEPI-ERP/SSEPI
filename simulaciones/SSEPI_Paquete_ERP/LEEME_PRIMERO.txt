Este paquete reúne las DOS herramientas que ya tienen datos cargados y explica
cómo usarlas juntas para la calculadora / siguiente orden de reparación.

  Carpeta raíz del proyecto:
  c:\Users\norbe\Documents\robot_mecanum_esp32_v3\escaner de imagenes\

  Esta carpeta (paquete):
  ...\escaner de imagenes\SSEPI_Paquete_ERP\

--------------------------------------------------------------------------------
INICIO RÁPIDO (dos servidores a la vez)
--------------------------------------------------------------------------------

  1) Doble clic: INICIAR_AMBOS.bat
     - Puerto 8765 → Editor de órdenes
     - Puerto 8766 → Comparador Odoo / Excel

  2) En el navegador:
     Editor:     http://127.0.0.1:8765/editor_ordenes.html
     Comparador: http://127.0.0.1:8766/comparador_clientes.html
     (En red: cambie 127.0.0.1 por la IP de su PC, ej. 192.168.101.14)

  Comparador (desde carpeta info):
    cd "...\escaner de imagenes\info"
    python generar_rastro.py
    python build_comparador.py

  Editor (desde carpeta raíz escaner de imagenes):

    (luego reiniciar iniciar_servidor.bat)
